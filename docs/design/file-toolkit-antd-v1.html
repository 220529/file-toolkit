Ant Design · 当前设计稿

小文喵文件工具箱界面设计

这是一套重新整理后的当前设计稿，直接覆盖旧交付物。产品定位是本地桌面文件工具箱， 打开即进入可操作工作台，不做营销首页。界面以 Ant Design 的布局、表格、表单、 进度、抽屉和确认反馈为基础，优先保证批量文件操作的安全、稳定和可核对。

桌面优先 预览先行 默认保守 任务可追踪 高风险需确认

视觉 Token

使用 AntD 语义色和 8px 以内圆角。页面背景克制，主工作区白底，辅助信息低对比， 主按钮和当前导航使用蓝色强调。

信息架构

文件文件统计、文件归类、批量重命名、文件去重。文件类功能都遵循“选择输入 -> 生成预览 -> 风险确认 -> 执行 -> 结果复查”。
视频视频截取、批量去头、格式转换。视频任务统一展示队列、进度、失败原因和输出路径。
图像水印处理。主区域是画布，右侧是模式、画笔、智能建议和导出控制。
系统任务中心、运行日志、关于。辅助系统默认收起，通过抽屉打开，不常驻挤占主流程。

统一交互规则

状态扫描、哈希、转换、删除、导出必须显示阶段、进度、当前对象和取消入口。
风险重命名、移动、删除、覆盖必须先预检。删除默认进回收站，彻底删除只能作为高级选项。
锁定任务运行中锁定输入路径和关键参数，避免执行结果与用户看到的预览不一致。
复查结果必须保留源路径、目标路径、成功数、跳过数、失败项和重试入口。
