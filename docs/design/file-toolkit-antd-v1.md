## 设计定位

小文喵是本地桌面文件工具箱，不是营销页、内容平台或云服务。界面打开即进入可操作工作台，优先级是：

- 稳定可靠：长任务有阶段、进度、取消和失败项。
- 预览先行：移动、删除、重命名、转换前先展示预览和风险。
- 默认保守：删除默认进入回收站，不默认覆盖。
- 高密度可扫读：表格、分组、标签和指标适合处理大量本地文件。
- 辅助信息按需打开：任务中心和日志使用抽屉，不常驻挤占主工作区。

## 核心页面

### 全局工作台 / 文件统计

- 左侧深色导航按“文件、视频、图像”分组。
- 顶部栏只放当前模块标题、重置当前、日志入口和当前主操作。
- 主体采用左侧输入参数、右侧结果预览。
- 文件统计是只读扫描，状态条明确展示“默认只读扫描”。

### 文件去重

- 扫描阶段拆为：扫描文件、大小初筛、哈希确认。
- 结果区展示重复分组、重复文件、预计释放、已选删除。
- 重复组列表按虚拟列表思路设计：只渲染可见组和 overscan。
- 删除默认进入回收站，并在确认弹窗中展示文件数、释放空间和失败项策略。
- 删除期间锁定选择，避免列表刷新导致误删。

### 视频截取

- 主区域聚焦视频预览和时间轴。
- 默认精确导出，强调结果接近预览。
- 快速导出需要校验结果时长，偏差过大时提示改用精确模式。
- 处理中锁定编辑，取消时终止 FFmpeg 并清理临时文件。

### 水印处理

- 主区域是图像画布和选区。
- 左侧放输入、处理模式、画笔和智能建议。
- 右侧抽屉承载任务和日志。
- 底部展示原图和结果对比，导出前要求复核边缘。

## 状态设计

- Toast：轻量成功、失败和输入错误。
- 页面状态条：当前模块的运行状态和关键风险。
- 任务中心：长任务列表、进度、取消入口。
- 日志抽屉：排查扫描、哈希、FFmpeg、图像处理问题。
- 确认弹窗：删除、覆盖、批量重命名等高风险操作。

## 响应式

窄窗口不做移动端独立产品形态，只保证桌面窗口缩窄时可用：

- 侧栏收起为图标栏。
- 主流程转为单列。
- 指标卡从 4 列转为 2 列或单列。
- 表格型内容转为摘要卡片。
- 重复组优先显示摘要，展开后再显示文件行。
