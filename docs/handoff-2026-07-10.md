## Completed

### 文件安全

- 新增 `src-tauri/src/commands/file_ops.rs`，统一绝对路径、普通文件、符号链接、平台大小写冲突和悬空链接判断。
- 归类/重命名使用原生无覆盖 rename；跨卷直接失败并保留源文件，不复制后删除。
- FFmpeg 输出写入目标目录下的私有临时目录，完成后无覆盖提交；取消/失败自动清理。
- 去重删除始终完整哈希复核，流式打开 candidate/keeper，避免大分组耗尽 FD；真正进入回收站前再次双哈希和身份复查。

### 任务与 UX

- 单视频、批量视频、转换、水印任务均按 task id 隔离进度和取消；延迟旧取消不会误杀新任务。
- FFmpeg 和 FFprobe 都进入任务进程槽；取消会停止当前进程并等待原任务结束。
- 视频导出准备阶段进入 TaskCenter，锁定重置和时间线编辑；卸载前再检查组件存活状态。
- 批量视频/水印取消返回部分结果，持久显示成功、失败和未处理数量，不再显示假 100%。
- 修复导入文件、清空、重复点击、保存路径检查和旧异步响应覆盖新状态等竞态。

### 隐私与发布

- 持久日志不记录文件名或路径；保留 7 天、最大 5MB，查看器最多读取最近 256KB/1000 行。
- Tauri asset protocol 静态 scope 收窄为 `$TEMP/**`，图片预览按用户选择的单文件动态授权。
- CI 先安装 pnpm 再启用 pnpm cache，并收紧到 `contents: read`。
- Release 改为手动 workflow，只接受现有 tag 和逐 target FFmpeg HTTPS archive/SHA-256，只产出 `release-draft` environment 下的 unsigned prerelease draft。
- `tag.sh` 改为本地版本准备脚本；不会 commit、tag、push 或触发发布。
