## 四、接口设计

### 4.1 Tauri Commands

| 命令 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `scan_directory` | `path: String` | `Vec<FileStats>` | 扫描目录统计 |
| `find_duplicates` | `path: String` | `Vec<DuplicateGroup>` | 查找重复文件 |
| `delete_files` | `paths: Vec<String>` | `u32` | 删除文件 |
| `cut_video` | `input, output, start, end` | `String` | 截取视频 |
| `get_video_duration` | `path: String` | `f64` | 获取视频时长 |
| `batch_trim_videos` | `paths, trim_start, output_mode` | `BatchTrimResult` | 批量去片头 |
| `convert_video` | `input, output, format, quality` | `String` | 格式转换 |
| `remove_watermark` | `input, selection, mode` | `CropResult` | 水印处理 |

### 4.2 Tauri Events

| 事件名 | Payload | 说明 |
|--------|---------|------|
| `file-stats-progress` | `FileStatsProgress` | 文件统计进度 |
| `dedup-progress` | `DedupProgress` | 去重进度 |
| `video-progress` | `f64` (0-100) | 视频截取进度 |
| `batch-video-progress` | `BatchTrimProgress` | 批量去片头进度 |
| `convert-progress` | `f64` (0-100) | 格式转换进度 |

## 五、错误处理

### 5.1 Rust 端

所有命令返回 `Result<T, String>`，错误信息会传递到前端：

```rust
#[tauri::command]
pub fn some_command() -> Result<Data, String> {
    do_something().map_err(|e| format!("操作失败: {}", e))?;
    Ok(data)
}
```

### 5.2 前端

统一错误处理：

```typescript
async function safeInvoke<T>(cmd: string, args?: object): Promise<T | null> {
  try {
    return await invoke<T>(cmd, args);
  } catch (e) {
    console.error(`Command ${cmd} failed:`, e);
    toast.error(String(e));
    return null;
  }
}
```

## 六、安全考虑

### 6.1 文件访问权限

Tauri 默认限制文件访问范围，需要在配置中声明：

```json
// tauri.conf.json
{
  "app": {
    "security": {
      "capabilities": [
        {
          "identifier": "default",
          "permissions": [
            "core:default",
            "dialog:default"
          ]
        }
      ]
    }
  }
}
```

### 6.2 删除操作保护

- 删除前必须用户确认
- 记录删除日志
- 考虑移动到回收站而非直接删除
- WebView 不直接读取文件内容，文件元信息、删除和处理动作通过受控 Rust 命令完成

```rust
// 可选：移动到回收站
use trash;

pub fn safe_delete(path: &str) -> Result<(), String> {
    trash::delete(path).map_err(|e| e.to_string())
}
```

## 七、性能指标

| 操作 | 目标性能 | 说明 |
|------|---------|------|
| 扫描 10000 文件 | < 2s | 纯遍历，不计算哈希 |
| xxHash3 校验 1GB 文件 | < 3s | 采样筛选 + 必要时全量校验 |
| 视频截取 | 实时 | 使用 -c copy 无损截取 |
| 格式转换 | 取决于编码参数 | FFmpeg 重编码 |
| 水印处理 | 秒级 | 取决于图片尺寸和修复模式 |

```typescript
// 用户配置
interface AppConfig {
  theme: 'light' | 'dark';
  ffmpegPath?: string;      // 自定义 FFmpeg 路径
  defaultOutputDir?: string; // 默认输出目录

```

配置存储在用户目录：
- macOS: `~/Library/Application Support/file-toolkit/config.json`
- Windows: `%APPDATA%/file-toolkit/config.json`
